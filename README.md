# Visual Studio DSA Programs in C (Only)

This repository contains **only the Visual Studio / practical-program topics** from your uploaded `Merged_Data_Structures_VisualStudio_LeetCode_Plan.numbers` plan. LeetCode questions have been excluded.

## Topics included
- Arrays: insertion, deletion, traversal, searching, merging, matrix addition/subtraction/multiplication, transpose
- Searching: linear and binary search
- Sorting: bubble, selection, insertion, merge, quick, radix sort
- Linked lists: singly linked list operations, polynomial addition, circular and doubly linked lists
- Stack: array and linked-list implementation, infix-to-postfix, postfix evaluation, balanced parentheses, Tower of Hanoi
- Queue: array queue, linked queue, circular queue, priority queue, deque
- Trees and BST: traversals, insertion, searching, deletion
- Heap and graph: heap/heap sort, adjacency matrix, BFS, DFS, Prim's MST, Dijkstra and Floyd-Warshall
- Value-added: static vs dynamic structures, top-10 hashtag selection, sorting student names

## Compile in VS Code
Open the `.c` file and use Terminal:

```bash
gcc path/to/file.c -std=c11 -Wall -Wextra -o program
./program
```

Each file is intended to be a standalone C program, except where noted in comments. Enter inputs as prompted or follow the comments at the top of the file.
